# Worders

> Worders is a Paris-area culturalization and localization company (a Partech portfolio company) that pairs brands with in-country linguists. Its platform (admin.worders.net, api.worders.net) runs on Ruby on Rails and exposes the Worders API V1 for freelance invoice verification and Plunet TMS order/quote automation, documented with an OpenAPI 3.0.1 spec served through Swagger UI.

The API authenticates with service API keys (`Authorization: Bearer wrd_live_...`) issued from the admin UI, or a Devise session cookie for browser traffic. List endpoints paginate with page/per_page and return a meta block (total/page/per_page). Errors use a `{"error": {"code", "message", "details"}}` envelope.

## APIs

- [Worders API V1 Swagger UI](https://api.worders.net/api-docs/index.html): interactive reference for the 13 endpoints (customers, freelancers, invoices, orders, purchase orders, quotes, Plunet templates)
- [OpenAPI 3.0.1 spec](https://api.worders.net/api-docs/v1/swagger.yaml): the machine-readable contract, base URL https://api.worders.net
